## Corrections to the spec (made on this branch)

- SPEC §4 and the roadmap say UniFi exports IPFIX "by default (checked,
  UniFi Network 9.3)". Not confirmed: the 8.5.6 release notes list v10, v9
  and v5, the help centre calls the feature "NetFlow (IPFIX)", and the 9.3
  announcement does not mention NetFlow. Recorded as unconfirmed; it does
  not matter in practice because Evan will choose IPFIX.
- SPEC §4 "verify in M0" on what is exported: answered from documentation
  in `docs/unifi.md` (sampling off by default, 5-minute active timeout,
  templates every 20 packets, switches do not export). The field list
  needs a capture from the gateway, which this session must not make.
- SPEC §7 "verify in M0" on `localfile`: `<log_format>json</log_format>`
  reads single-line JSON files; `location` takes wildcards (Wazuh 4.14
  docs). How the Windows-host file reaches the container is left to M3.
- Default port 2055 and the decided flow source written into SPEC §4.
