# M1: Wire decoding and generator
Machine: Ryzen 7 5700X desktop (Windows 11, Docker Desktop engine 29.8.2, cargo 1.99.1)   Date: 2026-11-22

## Built

- Workspace (Apache-2.0, `publish = false`, `unsafe_code = "forbid"` in
  every crate, no `cfg(target_os)`).
- `flowlanes-wire`: NetFlow v5 (Cisco v5 header and record tables), NetFlow
  v9 (RFC 3954) and IPFIX (RFC 7011) decoding; template store keyed by
  exporter address, version, observation domain / source ID and template
  ID; options templates (v9 and IPFIX) with scope fields marked;
  variable-length fields (both length forms); reduced-size integers;
  data held while its template is missing (limit per exporter and an age
  limit, then counted as rejected); per-exporter sequence tracking (v5 and
  IPFIX count records, v9 counts packets); counters for every way a packet,
  set or record is not decoded. Known elements come from a table of 53
  IANA elements (checked against the IANA CSV fetched 2026-11-22); every
  other element, and every enterprise element, is kept as ID (+ PEN) and
  raw bytes.
- `flowlanes-gen`: deterministic packets for v5, v9 and IPFIX traffic
  (IPv4 and IPv6, reduced-size counters, an enterprise element with the
  documentation PEN 32473, an unassigned IANA element, variable-length
  strings, NAT elements, options template and data), 18 malformed-packet
  kinds, a `mix`, and the flowlanes packet file format.
- `flowlanes` CLI: `decode <file>` (JSON lines on stdout, counters on
  stderr) and `generate --kind v5|v9|ipfix|malformed|mix` to a file or over
  UDP. 2055 is the documented default port (used from M2).
- Cross-check: `crates/flowlanes/tests/r1_goflow2.rs` runs
  `netsampler/goflow2:v2.2.7`
  (`sha256:b8fdc8f3666b05b0022ada3a3c8c50dcde97f7d19e3f42d050695fa0571fb952`,
  BSD-3-Clause) in Docker bound to 127.0.0.1:20555, sends the same
  generated packets over UDP on this machine and compares field values.
  The container is removed at the end of the test.

## Deviations and corrections

- **Template withdrawal (SPEC R2).** RFC 7011 §8.4: withdrawals MUST NOT be
  sent over UDP and MUST be ignored by UDP collectors. Since transport is
  UDP, withdrawals are counted and ignored by default and applied only with
  `Config::honor_withdrawals` / `--honor-withdrawals`. SPEC R2 updated.
- **R3 identity.** A data set without its template has an unknown number of
  records, so the decode-side identity is per data set; per record it holds
  for v5 and for every decoded set. SPEC R3 annotated.
- **`no_std`.** `flowlanes-wire` uses `std` collections; it has no I/O.
- **Build, not reuse** (decided in M0). `netflow_parser` remains an
  alternative.
- goflow2's v5/v9 start and end times were not compared (only IPFIX
  `flowStartMilliseconds`); its sampler address is the Docker gateway, not
  the generated exporter address, so exporter identity is not compared.
- Malformed packets were not sent to goflow2; how another collector handles
  them says nothing about ours.
- No performance figures: none were measured.
